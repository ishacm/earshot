how it works

Five steps, about a minute

  1. Read the websiteIt works out what the company does, the category, the claims it makes and its likely competitors. You confirm the competitors.
  2. Collect what people sayPublic comments from Hacker News, App Store reviews, Reddit (with your own key) and any CSV you export, like G2 reviews or support tickets.
  3. Tag every mentionPains, jobs to be done, objections, praise, reasons to switch. Each tag keeps an exact quote; paraphrases are thrown out.
  4. Count, then writeThemes are counted in code. The AI then writes messaging using only numbered evidence, and anything uncited is removed.
  5. Share the reportA clean web page and a Markdown file, plus an optional Slack summary every Monday through n8n.

what you get

A messaging brief you can defend

  • Positioning, three headline options and three message pillars, each linked to real quotes
  • The top pains, jobs to be done and objections, counted by how many people mention them
  • A battlecard per competitor: where they win and where they lose
  • The message-market gap: what the website promises that nobody talks about, and what customers raise that the website ignores

The demo uses a fictional company called Ledgerly and made-up comments, so it shows the format, not real findings.

try it in 60 seconds

No account, no API key, no cost

git clone https://github.com/ishacm/earshot && cd earshot
pip install -r requirements.txt
EARSHOT_LLM=mock python -m earshot.run --demo

Then open the report it prints. To run it on a real company, add a free Groq key: see the README.
